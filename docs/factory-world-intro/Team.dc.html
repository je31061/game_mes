한 명이 다 만들지 않고, 역할이 다른 셋이 규약으로 나눠 만들었습니다

설비를 실사형으로 바꾸고 실적 분석을 더한 스프린트 1은 인격이 다른 세 에이전트가 각자 담당을 맡고, 문서로 계약하고, 실제 결과물로 검증했습니다.

설비 3D 아티스트 · Blender

설비 유형 7종의 3D 모델을 Blender 스크립트로 만들고, 게임용 아이소메트릭 스프라이트를 렌더합니다. 실제 공장 설비를 만져 본 경험으로 형태를 잡습니다.

담당 파일 · 3D 모델 · 스프라이트 PNG · 매니페스트 · 설비 유형 체계

실적 분석 · OEE
가동률
RUN 시간 ÷ 계획 가동 시간

설비가 실제로 가동한 시간의 비율. 계획 시간은 운영 정책 "1일 계획 가동 시간"으로 정하고, 없으면 24시간으로 봅니다.

성능
실적(양품 + 불량) ÷ 목표 수량

작업지시 목표 대비 생산한 수량의 비율.

품질
양품 ÷ (양품 + 불량)

생산한 것 중 양품의 비율.

OEE
가동률 × 성능 × 품질

셋을 곱한 종합 설비 효율. 설비별로 보고, 요약은 합계로 다시 계산합니다.

근거 없는 숫자는 내지 않습니다

목표가 없으면 "—"로 비웁니다. 첫 로그 이전 시간은 추정하지 않고 "상태 미확인"으로 따로 보고합니다. 셋 중 하나라도 없으면 OEE도 비웁니다.

같은 탭에서 일별 생산실적과 게이트웨이 연결 품질도 봅니다. 외부 차트 라이브러리 없이 인라인 SVG로 그립니다.

실사형으로 바꿔도 이벤트 규격·관리자 동선은 그대로다.

설비 하나 늘릴 때 코드가 아니라 유형 하나를 고릅니다.
