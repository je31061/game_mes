1접속과 로그인

  • 주소: 사내 서버 주소는 시스템 담당자가 안내합니다. 체험용 공개 서버는 factory-world.onrender.com입니다.
  • 권장 환경: PC의 크롬·엣지 브라우저, 현장 태블릿(크롬). 별도 설치는 없습니다.
  • 로그인: 사번 · 이름 · 비밀번호를 입력하고 [접 속]을 누릅니다. 등록된 사번은 첫 로그인 때 입력한 비밀번호가 그대로 등록됩니다(4자 이상).
  • "등록되지 않은 사번"이라고 나오면 관리자에게 사용자 등록을 요청하세요.
  • 로그인 유지: 로그인은 12시간 유지됩니다. 새로고침, 테마 전환, 관리자 콘솔과 오갈 때 다시 로그인하지 않습니다.
  • 로그아웃: 상단 🚪. 여러 사람이 쓰는 PC·태블릿은 사용 후 꼭 로그아웃하세요.
  • 비밀번호 변경: 상단 🔑 → 현재 비밀번호와 새 비밀번호(두 번) 입력.

2캐릭터 설정과 출근

  1. 캐릭터 색상을 고르고 닉네임을 적습니다(기본은 내 이름).
  2. 직무 뱃지를 고릅니다: 작업자 · 설비 보전 · 생산 관리자 · 품질.
  3. [🏭 출근하기]를 누르면 공장 맵에 입장합니다. 한 번 설정하면 다음부터는 이 화면 없이 바로 출근합니다.

입장하면 출근 브리핑 창이 진행 중인 알람, 모집 중인 작업지시, 오늘의 공지를 보여 줍니다. 알릴 것이 없으면 뜨지 않습니다.

4이동과 설비 확인

이동

↑ ↓ ← → 또는 W A S D, 맵의 원하는 곳을 클릭해도 걸어갑니다. 태블릿은 터치하거나 왼쪽 아래 방향 패드를 씁니다.

설비 색

가동   대기   정지   알람(깜빡임)

설비 사이의 선은 공정 라인입니다. 선이 초록 → 노랑 → 주황 → 빨강으로 바뀔수록 중간 재공이 쌓인 것이며, 90%를 넘으면 "라인 정체" 알림이 뜹니다.

설비를 클릭하면 — 상태창

  • 기본 정보: 설비명·코드, 위치(존), 담당자, 현재 상태와 지속 시간
  • 게이지: 금일 가동 비율, 작업지시 목표 대비 진행률
  • 최근 이력 · 첨부 문서: 상태 변경 기록과 이 설비 대화방에 올라온 파일
  • 공정 · 단품: 이 설비가 맡은 공정(공정번호, 사이클 타임, 품질 관리 항목)과 투입되는 부품 목록(사진·품번·품명·규격·수량). 🔩 분해도를 누르면 제품 분해도에서 이 공정의 단계가 강조됩니다.
  • 버튼: 💬 대화방 열기(현장에 없어도 원격 참여), 📣 담당자 호출(담당자에게 알림 + 이력 기록)
  • 상태 변경(보전·관리자만): 가동 / 대기 / 정지 / 알람을 누르고, 필요하면 사유를 적습니다.

5대화와 파일 공유

  • 자동 대화방: 같은 설비 가까이(약 2.4칸)에 두 명 이상 모이면 그 설비의 대화방이 자동으로 열립니다.
  • 대화 패널 💬 대화: 📢 전체 채널과 🏭 설비 채널이 탭으로 나뉩니다. 읽지 않은 메시지는 빨간 점으로 표시됩니다.
  • 파일 보내기: 📎를 누르거나 파일을 대화 패널에 끌어다 놓습니다. 사진, PDF, 도면(DWG·DXF), 동영상(MP4), 엑셀·워드·파워포인트, 텍스트·CSV 파일을 25MB까지 올릴 수 있습니다.
  • 대화·파일·상태 변경은 그 설비의 이력으로 남고 수정·삭제할 수 없습니다. 업무 내용만 적어 주세요.

6알람 대응 순서 (예시)

  1. "🚨 ○○ 알람 발생!" 알림이 뜨고, 맵에서 해당 설비가 빨갛게 깜빡입니다.
  2. 현장 작업자와 보전 담당이 각자 캐릭터를 그 설비 앞으로 옮깁니다. 사무실에서는 상태창의 [💬 대화방 열기]로 참여해도 됩니다.
  3. 두 사람이 가까워지면 설비 대화방이 자동으로 열립니다.
  4. 현장 사진, 점검 매뉴얼 PDF를 주고받으며 조치 방법을 정합니다.
  5. 조치가 끝나면 보전 담당이 상태를 가동으로 바꾸고 사유를 적습니다. 알람을 해제한 사람에게 포인트가 쌓입니다.
  6. 대화·파일·소요 시간이 설비 이력으로 저장되어, 같은 문제가 다시 생기면 찾아볼 수 있습니다.

7작업지시(임무)와 포인트

  • 📜 임무에서 모집 중인 작업지시를 [✋ 수락하기] → 작업 → [✅ 완료 등록]에 양품·불량 수량과 비고를 입력합니다.
  • 포인트: 작업지시 완료 +100P(불량 0이면 +20P 보너스), 알람 해제 +50P. 포인트가 쌓이면 레벨이 오릅니다.
  • 뱃지: 🎖 첫 임무 완수 · 🏅 임무 베테랑(5건) · 🚨 알람 해결사(해제 3회) · 💎 무결점(불량 0 실적 3회)
  • 🏆 리더보드에서 개인 순위(상위 10명)와 팀 순위를 봅니다.

10문제 해결

증상해결
첫 화면이 뜨는 데 30~60초 걸린다체험 서버는 무료 서버라 한동안 접속이 없으면 잠듭니다. 잠시 기다리면 열립니다. 사내 서버는 해당 없음.
"등록되지 않은 사번"관리자에게 사용자 등록을 요청하세요. 등록 후 첫 로그인 때 비밀번호를 정합니다.
비밀번호를 잊었다관리자에게 비밀번호 초기화를 요청한 뒤, 다음 로그인 때 새 비밀번호를 입력하면 그대로 등록됩니다.
상태 변경 버튼이 흐리다설비 상태 변경은 보전·관리자만 할 수 있습니다.
대화방이 열리지 않는다설비에 더 가까이 가거나, 상태창의 [💬 대화방 열기]를 누르세요. 자동 대화방은 두 명 이상일 때 열립니다.
화면이 끊기거나 느리다상단 ⚡ 저사양 모드를 켜세요.
"세션이 만료되었습니다"로그인한 지 12시간이 지났습니다. 다시 로그인하세요.
다른 사람 이름으로 들어가 있다공용 기기에 이전 사용자의 로그인이 남은 것입니다. 🚪 로그아웃 후 본인 사번으로 로그인하세요.
체험 서버의 데이터가 사라졌다체험 서버는 업데이트될 때마다 초기 데이터로 돌아갑니다. 실제 운영은 사내 서버에서 합니다.
